# PG Finder

Full-stack PG Finder application with React + Vite frontend and Node/Express backend.

## Structure
- `backend/` Express API with MongoDB, JWT auth, Cloudinary uploads
- `frontend/` React app with Tailwind, React Router, React Query

## Environment variables
Create `.env` files based on the examples.

### Backend
```
cp backend/.env.example backend/.env
```

### Frontend
```
cp frontend/.env.example frontend/.env
```

## Running locally
```
cd backend
npm install
npm run dev
```

```
cd frontend
npm install
npm run dev
```
